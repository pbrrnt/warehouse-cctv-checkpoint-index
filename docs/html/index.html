ระบบดัชนีสืบค้นภาพจากกล้องวงจรปิด·เอกสารทั้งหมด

เอกสารโครงการ

ระบบช่วยจำกัดวงการค้นหาสำหรับโกดังที่มี NVR อยู่แล้ว วิเคราะห์ภาพจากกล้องจุดคอขวดเพื่อบอกว่าใครหรืออะไรผ่านเข้า–ออกเมื่อไร

  • 00บันทึกการตัดสินใจบันทึกการตัดสินใจ (ADR) และสิ่งที่ยังไม่ตัดสินใจ
  • 01สถาปัตยกรรมระบบสถาปัตยกรรมระบบและเหตุผลของแต่ละทางเลือก
  • 02จัดขนาดเครื่องและพื้นที่เลือกเครื่อง และสูตรคำนวณพื้นที่จัดเก็บ
  • 03การนำกล้องเข้าระบบเทคนิคการต่อกล้อง Dahua/ONVIF และกับดักที่พบบ่อย
  • 04โครงสร้างฐานข้อมูลโครงสร้างฐานข้อมูล index และคิวรีตัวอย่าง
  • 05การอ่านป้ายทะเบียนไทยป้ายทะเบียนไทย รูปแบบ ตารางอักษรสับสน 77 จังหวัด
  • 06การปฏิบัติตาม PDPAหน้าที่ตามกฎหมาย และการควบคุมทางเทคนิค
  • 07การดูแลระบบเฝ้าระวัง สำรองข้อมูล และแก้ปัญหา
  • 08การเชื่อมต่อกับ NVRการซิงก์เวลา และขั้นตอนของเจ้าหน้าที่
  • 09Runbook เปิดโกดังใหม่เช็กลิสต์เปิดโกดังใหม่ตั้งแต่สำรวจถึงส่งมอบ
  • 10การออกแบบจุดคอขวดสเปกกล้อง ไฟส่องสว่าง และเกณฑ์ตรวจรับงานติดตั้ง
  • 11testing

เล่มที่ขีดเส้นสีไว้คือเล่มที่มีผลต่อความสำเร็จมากที่สุด ช่างติดตั้งอ่านเล่ม 10 ก่อน
